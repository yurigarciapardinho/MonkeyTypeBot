# MonkeyTypeBot



- This repository contains a Python script that automates typing on the monkeytype.com with 100% accuracy.

- The script is designed to prevent detection as a bot.

- It works on every  `Typing mode` and `Time` constraint also . 



### Steps to Follow



- First install the chrome webdriver from \[Chrome Driver](https://chromedriver.chromium.org/downloads) and ADD IT TO PATH.

```

git clone https://github.com/Adity4Saini/MonkeyTypeBot

cd MonkeyTypeBot

pip install -r requirements.txt

python monkeytype.py

```
